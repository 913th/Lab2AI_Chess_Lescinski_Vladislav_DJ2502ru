## Описание игры и правила

Мини-шахматы на доске **5×5**. Фигур три вида: король, ладья и пешка.

| Сторона | Цвет фигур | Расположение | Кто играет |
|---------|------------|--------------|------------|
| Человек | красные    | снизу        | мышью, ходит первым |
| ИИ      | чёрные     | сверху       | Minimax |

**Начальная расстановка** 
<img width="583" height="581" alt="Снимок экрана 2026-10-19 133358" src="https://github.com/user-attachments/assets/ba2d5fbe-7bb8-4f65-8294-c0097ba3eab5" />


**Правила движения:**

- **Король** ходит на одну клетку в любом направлении.
- **Ладья** ходит по горизонтали и вертикали на любое число свободных клеток, может взять первую встретившуюся фигуру противника.
- **Пешка** ходит на одну клетку вперёд, если клетка свободна, и бьёт по диагонали вперёд. Двойного хода нет. Дойдя до последней линии, превращается в ладью.

**Упрощения (по условию лабораторной):** нет рокировки, взятия на проходе и других сложных правил.

**Конец партии:**

- **Мат** — у игрока нет допустимых ходов, а его король под шахом. Игрок проиграл.
- **Пат** — допустимых ходов нет, но король не под шахом. Ничья.
- **Ничья по правилу прогресса** — 40 полуходов подряд без взятий и ходов пешек.

Король не может остаться (или встать) под шах, поэтому король не «берётся» как обычная фигура, партия заканчивается матом.

## Как запустить

### Требования

- Unity Hub и Unity **2022.3 LTS** (проект создан в 2022.3.62f3; подойдёт любая 2022.3.x).
- Если в проекте включена только новая Input System: `Edit → Project Settings → Player → Active Input Handling` → **Both** (или **Input Manager (Old)**). Иначе мышь не будет работать.

### Запуск

1. Склонируйте репозиторий:
   ```bash
   git clone <ссылка-на-репозиторий>
   ```
2. Откройте **Unity Hub** → **Add → Add project from disk** → выберите папку проекта.
3. Откройте проект (Unity сама выберет подходящую версию или предложит установить её).
4. В окне **Project** откройте сцену `Assets/Scenes/SampleScene.unity`.
5. В окне **Hierarchy** выберите объект `GameManager`. В Inspector у скрипта `Sprite Game Controller` должно быть:
   - `Human Prefix` = `Red`
   - `Ai Prefix` = `Black`
   - `Search Depth` = `4` (допустимо 1–6)
6. Нажмите кнопку **Play**.

## Как играть

1. Человек играет **красными фигурами снизу** и ходит первым.
2. Кликните по своей фигуре: клетка подсветится **жёлтым**, допустимые ходы **зелёным**.
3. Кликните по зелёной клетке — фигура сходит. Взятые фигуры исчезают с доски.
4. ИИ отвечает ходом чёрных. Клетки последнего хода подсвечиваются **синим**.
5. Чтобы выбрать другую фигуру, кликните по ней. Клик по любой другой клетке снимает выбор.
6. Кнопка **«Новая игра»** в левой части экрана возвращает фигуры на начальные места.

В левой части экрана отображаются:

- статус партии («Ваш ход», «ШАХ!», «ИИ думает...», результат);
- последний ход ИИ в формате `e5-e4` (буква — столбец a–e слева направо, цифра — линия 1–5 снизу вверх);
- **оценка** выбранного хода, **число просмотренных узлов**, **глубина** поиска и **время** расчёта.

## Реализация ИИ

### Состояние игры

Доска хранится в массиве `int[25]` (индекс = `строка * 5 + столбец`). Значения: `0` пустая клетка, `1` пешка, `2` ладья, `3` король. Знак показывает сторону: положительные числа — фигуры человека, отрицательные — фигуры ИИ.

Функция применения хода возвращает **новое** состояние, а не изменяет старое, поэтому дерево поиска строится без «отката» ходов.

### Алгоритм Minimax

ИИ строит дерево возможных ходов:

- на уровнях **своего хода** выбирает **максимум** оценки;
- на уровнях **хода человека** выбирает **минимум** оценки;
- в терминальных состояниях (мат, пат, ничья) возвращает точную оценку;
- при достижении предельной глубины вызывает эвристическую оценку позиции `Evaluate`.

В результате ИИ выбирает ход, который даёт наилучший результат при **наихудшем для него ответе** соперника.

Для ускорения применено **альфа-бета отсечение** (не меняет результат поиска, только отбрасывает заведомо бесполезные ветки) и упорядочивание ходов (взятия просматриваются первыми).

```csharp
int Minimax(GameState s, int depth, bool isMaximizing, int alpha, int beta)
```

### Оценочная функция `Evaluate(state)`

Оценка считается **с точки зрения ИИ** (больше — лучше для ИИ):

| Составляющая | Значение |
|--------------|----------|
| Пешка | 1 (в коде 100) |
| Ладья | 5 (в коде 500) |
| Король | 1000 (в коде 100000) |
| Бонус пешке за продвижение | +10 за каждую пройденную линию |
| Бонус ладье за центральный столбец | +5 |
| Мат | ±1 000 000 (с поправкой на глубину: быстрый мат предпочтительнее) |
| Пат, ничья | 0 |

Значения материала умножены на 100, чтобы можно было добавить небольшие позиционные бонусы целыми числами. Соотношение 1 : 5 : 1000 соответствует условию.

### Ограничение глубины

Число ходов растёт как `b^d` (`b` — среднее число допустимых ходов, `d` — глубина), поэтому полный перебор до конца партии слишком медленный. Поиск ограничен глубиной **4 полуходов** (по умолчанию, допустимо 1–6; в условии требуется 2–4). На границе глубины используется эвристика `Evaluate`.

## Соответствие требованиям лабораторной

| Требование | Где реализовано |
|------------|-----------------|
| Структура игрового состояния | `GameState.cs`, класс `GameState` |
| Функция получения всех допустимых ходов | `GameState.GetLegalMoves()` |

| Учёт шаха, мата и пата | `GetLegalMoves()` отбрасывает ходы, оставляющие своего короля под шахом; `GetStatus()` |
| README.md с инструкцией по запуску | этот файл |
| Отчёт в формате Markdown | `REPORT.md` |

## Устройство сцены

Скрипт `SpriteGameController` сам находит клетки и фигуры по сцене, поэтому важно соблюдать:

- Объект **`ChessBoard`** содержит ровно **25 клеток** (дочерние объекты со `Sprite Renderer`), расставленных в ровную сетку 5×5. Фоновое изображение должно лежать вне `ChessBoard`.
- Имена фигур начинаются с `Red` (человек, снизу) или `Black` (ИИ, сверху) и содержат `King`, `Rook` или `Pawn`, например `RedKing`, `BlackRook 1`, `RedPawn 3`.
- Всего 16 фигур: по одному королю, две ладьи и пять пешек у каждой стороны.
- Объект **`GameManager`** — пустой объект со скриптом `SpriteGameController`.
- Камера — объект с тегом `MainCamera` (Orthographic).

Начальная расстановка определяется положением фигур в сцене. Чтобы изменить её, достаточно передвинуть фигуры и перезапустить игру.

## Возможные проблемы

| Проблема | Что делать |
|----------|-----------|
| Ошибка «ожидалось 25 клеток» | Проверьте, что внутри `ChessBoard` ровно 25 объектов со Sprite Renderer |
| Предупреждение «Найдено фигур: N» | Проверьте имена фигур (`Red…`/`Black…` + `King`/`Rook`/`Pawn`) |
| Клики не работают | У камеры должен быть тег `MainCamera`; включите `Active Input Handling = Both` |
| «Король человека должен стоять на нижней линии» | Красные фигуры должны стоять снизу; иначе поменяйте `Human Prefix` и `Ai Prefix` |
| Значения префиксов в коде не применяются | Unity хранит значения из Inspector, поменяйте их вручную на объекте `GameManager` |
| ИИ думает слишком долго | Уменьшите `Search Depth` до 3 |
